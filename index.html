OpenCat User Manual

A step-by-step guide to processing borehole imaging data, reviewing logs, and producing engineering files and 3D renders.

Contents

1. Overview

OpenCat turns raw downhole imaging passes into reviewable logs and shareable 3D models. You sign in, open a project, choose the depth interval and processing options, and press Run. OpenCat reconstructs the borehole surface, displays it as synchronized log tracks, and lets you export the result as industry-standard engineering files or as an interactive 3D “GaussSplat” render.

What you can do with it

  • Reconstruct the borehole surface from an imaging pass using a configurable radial search window and a statistical operator (mean, median, mode, min, or max).
  • Review the result live in five linked panels: high-resolution tube view, full amplitude image with log curve, background image with gamma, radii map with well inclination, and a raw single-depth frame with the detected surface overlaid.
  • Clean up the image with normalization, ECC jitter correction, standard-deviation color clipping, and a Gaussian smoothing filter.
  • Export engineering logs in DLIS, LAS, and DV Caliper formats.
  • Generate 3D renders (GaussSplat .ply + a standalone web viewer) and record rotation or flythrough .mp4 videos.
The big picture: Sign in → Open a project → Run → Review → Export (engineering files and/or 3D renders). Most day-to-day work is repeating Run with small changes until the log looks right, then exporting.

2. Quick Start

  1. Sign in. Enter your username and password, pick the environment (prod for normal work), and click Login.
  2. Open a project. Paste a project URL, or Browse to a .dvproj or opencat_params.json file (or pick a ticket from the DVT list), then click Continue.
  3. Choose what to process. Select the Pass Uid, a Map Uid (surface map), and the depth interval in Slices.
  4. Press Run. Watch the progress bar; the five panels fill in when processing finishes.
  5. Review and fine-tune. Adjust Window, Offset, the inline operator, and the filters, then use Refresh Frames to re-apply them quickly (no full reprocess).
  6. Export engineering files. Click Export and choose DLIS, LAS, or DV Caliper.
  7. Build a 3D render (optional). Open Renders, set the options, and click Generate GaussSplat to create the model and open the 3D viewer.

3. Signing In

  • Username & Password — your OpenCat account credentials.
  • Select Environment — the server you connect to: prod (production — use this for normal work), train, dev, and qa.
  • Login — signs in and opens the Open Project window.
If you are already signed in from a previous session, OpenCat skips the password fields and shows only the environment selector with a Continue button. Changing the environment restarts the application so it can reconnect.

4. Opening a Project

Three ways to open a project

  • Project URL — paste the full project link into the path field.
  • A file — click Browse and pick a .dvproj file or an opencat_params.json parameters file.
  • A DVT ticket — start typing in the DVT selector to search tickets in the database; choosing one fills in the path automatically.

Data Base Sync Method

Controls how much project data is downloaded before opening:

OptionWhat it does
FullDownloads everything, including compressed maps. Most complete — use when you need all maps available offline.
NoCompressedMapsSyncs the project but skips the large compressed map files. Faster to open.
NoSyncingOpens using only what is already on disk. Fastest, but requires that the project was synced earlier.

Click Continue to load the project and open the Main Window.

5. The Main Window

5.1 Top bar

  • Environment / Project — shows the active server and the open project path or URL.
  • Log Date — the log date used in metadata and export filenames. It is editable; the field changes color while you are editing to remind you to confirm the value.
  • Renders — opens the Renders Setup window for building 3D models.
  • Settings — opens the Settings window.

5.2 Input panel (left side)

These controls define what to process and how. Any field you change is highlighted so you can see at a glance what differs from the loaded project.

Well information — identifying text that is written into every export filename and log header:

  • Well — well name.
  • Well ID — unique well identifier.
  • Company — operating company.
  • Field — field name.

Data selection — which pass, map, and depth range to process:

ControlWhat it does
Pass UidChooses which imaging pass to load. Changing it reloads that pass’s default settings.
Map UidSelects a named surface map. Picking one updates the depth range to match the map.
SlicesA list of named depth bookmarks. Selecting one fills in the start and end depth fields next to it.
Start / End depthThe first and last depth (in the current unit) of the interval to process. You can type these directly.

Surface reconstruction — how the borehole surface is found in each frame:

ControlWhat it does
WindowHalf-width (in samples) of the radial search band around the surface profile. Slider range 1–300. Wider windows capture more of the wall but include more noise.
OffsetRadial shift (−300 to 300 samples) applied to re-center that search band on the surface.
Rad InlineThe statistical operator collapsed across the window to build the surface profile: mean, median, mode, min, or max.

Image cleanup — corrections and filtering applied to the displayed image:

ControlWhat it does
NormNormalizes amplitude per row to reduce gain differences between frames.
ECCEnhanced Correlation Coefficient alignment — reduces frame-to-frame jitter. The adjacent field is the blending factor (0.0 = off, 1.0 = full correction).
StdNumber of standard deviations used to clip amplitudes when setting the color-scale limits. Slider range 0.1–10.0.
Gauss FilterStrength of the Gaussian smoothing filter (0 = disabled, up to 1.0).

Performance — trade resolution for speed:

  • Rad Decimation — downsamples around the borehole (angular resolution).
  • Depth Decimation — downsamples along depth.

Higher decimation values process faster but produce a coarser image — useful for a quick first look at a long interval.

5.3 Action buttons

ButtonWhat it does
RunRuns the full processing pipeline on the chosen interval: reconstructs the surface, computes every track, and fills the panels. A progress bar shows status and the buttons are disabled until it finishes.
Refresh FramesRe-applies display settings — Window, Offset, Rad Inline, Norm, ECC, Std, and Gauss Filter — to data from the most recent Run, without reprocessing from scratch. Much faster for fine-tuning. Requires a prior Run.
ExportOpens the save dialog to write engineering files. See Exports & Output Files.

5.4 The plot panels

The right side shows five linked panels. Click any depth in the tracks to move the active depth marker — the high-resolution view and the raw frame at the bottom update to match, and the Slice Depth readout shows the exact depth selected.

PanelShows
Tube (HD)High-resolution tube view centered on the surface, with a white line marking the currently selected depth.
Amplitude imageFull tube image with the scan angle (cyan) and the amplitude log (white) curves overlaid. Right axis: Amplitude (mV).
Background + GammaBackground-subtracted image with the gamma (natural radioactivity, green) curve. Top axis: Gamma (cps).
Radii + InclinationCasing/formation radii map with the well inclination (cyan) curve. Top axis: Well Inclination (Deg).
Raw frameThe single raw frame at the selected depth, with the detected surface (magenta) and the window boundaries (cyan) drawn on top, plus an amplitude colorbar.
Tip: If the output looks identical after a run, confirm that you actually changed a setting or the depth range. For quick visual tweaks (filters, window, offset), use Refresh Frames instead of Run — it is much faster because it reuses the already-processed data.

About the asterisk (*): fields marked * are processing (“VizApp”) options. Changing them only takes effect after you press Run again — the window reminds you with “*VizApp options, Re-run required.”

Click Close to save and return. Remember to Run again for any * change to take effect.

7. Renders Setup

The Renders Setup window builds a 3D GaussSplat model of the processed interval and opens it in the built-in 3D viewer. There are two rendering modes.

7.1 Mode: Image vs. Volume

The GaussSplat - Mode toggle (top-left) switches between two ways of building the model. The Interpolated toggle uses depth-interpolated frames for a smoother result; turning it off uses raw frames.

7.2 Mode-specific controls

Image mode only:

  • Image Type — Inline (radial statistical surface) or Background (constrained to one standard deviation).
  • Browse …merge object — optionally pick a .npz object file to merge into the render.
  • Sampling Length / Sampling Circular — number of samples along depth and around the circumference.
  • Z Scale / Radius Scale — scale multipliers along the axis and radially.

Volume mode only:

  • Frames — Raw or Filtered (noise-reduced) frame data.
  • Min Value Cutoff — values below this threshold are excluded from the volume.

7.3 Color & appearance (both modes)

ControlWhat it does
Color MapColor palette for the render (e.g. viridis, RdYlBu, berlin, turbo, and many more).
Invert ColorsReverses the palette (near ↔ far).
Radial DistanceColors splats by distance from the borehole axis. Enables the Casing Size, ID/OD, and Texture Intensity controls.
Casing SizePick a standard casing size; this fills the ID/OD fields.
ID/ODInner and outer diameter values used for the casing reference.
Texture IntensityHow strongly surface texture is blended into the coloring.
AlphaBase opacity of the splats (0 = transparent, 1 = opaque).
Linear / AmplitudeLinear uses one opacity for all splats; Amplitude scales opacity with each splat’s amplitude.

7.4 Generate

ControlWhat it does

OrientationNorth, TOH (top of hole), or None — the reference the model is oriented to.

7.5 Bookmarks

The Bookmarks button (in Renders Setup) opens a window for placing labelled markers on the 3D model. Each bookmark is a depth, a text label, and a scan angle — together they pin a leader line and a floating label to a specific spot on the borehole wall. The list is saved with the render parameters and the markers appear in the 3D viewer, where the B key shows or hides them.

Two ways to fill the list

  • Import from the database — tick the categories you want, then click Import to pull every matching marker that falls within the currently processed depth interval. (This replaces the rows in the table.)
  • Add by hand — click + Add Row for a blank row and type in the depth, a label, and the scan angle yourself.

Category checkboxes

These select which kinds of database markers Import brings in:

CheckboxImports
OtherFlagsGeneral-purpose “quick flag” markers placed on the pass.
PerfFlagsPerforation quick-flag markers.
BreachesBreach features (from the saved range/spline features).
PerfsPerforation-exit features.

The table

ColumnMeaning
DepthDepth of the marker, in the current unit (ft or m). Imported depths are filled in automatically.
BookmarkThe text label shown next to the marker in the 3D model.
ScanAngleAngle around the borehole (degrees) where the leader line attaches to the wall.
Editing & saving: when you change a cell it turns orange to show it is unconfirmed. Press Enter in that cell to confirm and save it. Bookmarks save automatically as you confirm edits, so the markers update in the Renders window in real time — a row is only kept once all three fields (depth, label, scan angle) are filled in.

8. The 3D Viewer

After Generate GaussSplat, OpenCat opens the render in an embedded interactive viewer.

9. Exports & Output Files

9.1 Engineering exports (the Export button)

Click Export in the main window and choose a format in the save dialog. Files are named automatically from the well metadata, pass, interval, and log date. A matching .json parameters file is saved alongside so the run can be reloaded later.

FormatFiles produced
DLISA single .dlis file containing every computed channel (tube, background, radii, log, scan angle, inclination, gamma, temperature, ovality, phase major axis, decentralization, speed-of-sound).
LASTwo files: …_Image.las (image and geometry channels) and …_FPT.las (gamma, temperature, ovality, phase major axis, decentralization, speed-of-sound).
DV CaliperOne .dvcaliper file per channel, e.g. …_Image, …_ImageBG, …_Radii, …_AmpLog, …_ScanAngle, …_InclinationAngle, …_Gamma, …_Temperature, …_Ovality, …_PhaseMajorAxis, …_Decentralization, …_SpeedOfSound.

9.2 3D render outputs (Generate GaussSplat)

Generating a render writes a set of files that share one base name:

FileContents
.plyThe GaussSplat model itself (SuperSplat format).
.htmlA standalone, shareable web viewer — open it in any browser, no OpenCat required.
_data.npzThe underlying point data (positions, colors, normals) for reuse.
.jsonThe parameters used, for reproducibility.
…Video.mp4Optional rotation and/or flythrough videos exported from the viewer.

10. Troubleshooting

ProblemWhat to check
Login failsConfirm your username/password and that the correct environment is selected (usually prod).
Project won’t openVerify the URL/file path. If you chose NoSyncing, the project must already be on disk — try Full or NoCompressedMaps.
Run won’t startMake sure a Pass Uid is selected and the start/end depths form a valid interval.
Output looks unchanged after RunConfirm you actually changed a setting or the depth range. For display-only tweaks use Refresh Frames.
Processing is slowIncrease Rad/Depth Decimation, shorten the interval, or switch Blast Processing to GPU.
A Settings change had no effectOptions marked * require a re-run — press Run again.
3D viewer is blankClick Viewer to regenerate, or the ↻ refresh button to reload.
Video export failsMake sure the viewer has fully loaded before exporting a Rotation or Flythrough video.

11. Glossary

TermMeaning
PassOne run of the imaging tool through the borehole. A project may contain several.
Surface mapA named profile of the borehole wall used as the starting reference for reconstruction.
SliceA single depth position; the “Slices” range is the depth interval you process.
TubeThe unrolled image of the borehole wall (depth vertically, circumference horizontally).
Inline operatorThe statistic (mean/median/mode/min/max) used to collapse the radial window into one surface value.
ECCEnhanced Correlation Coefficient — alignment that reduces jitter between frames.
SOSSpeed of Sound — used to correct measured distances and depth.
DecimationDownsampling to trade resolution for speed.
GaussSplatA 3D Gaussian-splatting model — a point-cloud-like representation rendered interactively in the viewer.
TOHTop Of Hole — an orientation reference used in deviated or horizontal wells.
DVTA ticket/job identifier used to look up a project in the database.
